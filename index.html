Simple

第一步 · 基础交互 · Mock

最简单的 Passkey / WebAuthn 登录示例， 不包含密码，专注理解 Passkey 的基本注册、 登录和管理流程。

  • 无需密码
  • 注册账户
  • 注册 Passkey
  • 使用 Passkey 登录
  • 启用 / 禁用 Passkey

Complete

第二步 · 密码 + Passkey · Mock

在 Simple 版本基础上增加密码认证， 用于理解真实账户系统中密码与 Passkey 如何配合使用。

  • 账户注册 + 密码
  • 账户名 + 密码登录
  • 密码验证后注册 Passkey
  • 使用 Passkey 登录
  • 启用 / 禁用 Passkey
进入 Complete →
🐍

Complete Python

第三步 · FastAPI + MySQL · 真实接口

保留 Complete 的账户交互，由服务器验证密码和 WebAuthn 响应， 保存凭证公钥并建立真实登录 Session。

  • Argon2id 密码验证
  • 服务端 Challenge 与验签
  • MySQL 保存账户和凭证
  • HttpOnly Cookie 登录态
  • 需先完成 Python 示例数据库配置
进入 Complete Python →

建议先体验 Simple ，再对比 Complete ，最后体验 Complete Python ，了解同一套流程如何接入真实后端。
